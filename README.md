# スマートプロジェクト(デジタル版)

Web 制作会社を舞台にした4〜5人協力型ボードゲーム。
現在 **ステージ1(ルールエンジン + ホットシートUI)+ ルール v5**。

- ルールの単一の正: [docs/RULES.md](docs/RULES.md)
- アーキテクチャ方針: [CLAUDE.md](CLAUDE.md)

## v5 で入った再設計

v4(工数モデル)を土台に、Issue #1〜#9 の裁定を統合しました。数値はすべて `GameConfig` から調整できます。

| # | テーマ | 内容 |
|---|---|---|
| #1 | **スコープ管理** | 「約束」を廃止。要件を **Must / Better / 見送り** の3区分と**期限**で管理する(RULES.md §3) |
| #8 | **CS 経済** | Better 達成で CS+1、期限フェーズの Must 全達成で**信頼ボーナス**、イベントの追加対応をやり切ると CS+1(§4) |
| #3 | **見積差異** | カードには**見積工数とリスク**だけが刷ってある。**実工数**は着手した週の週末に公開される(§2-2) |
| #5 | **品質リスク** | Lv1 納品は**品質リスク**を残す。手戻り・バグに狙われやすく、対応工数も増える。Lv2 化で消える(§2-4) |
| #2 | **ローリング計画** | 起点/中盤/仕上げのレーンを廃止し、**Backlog + 3週の計画ボード**へ。週ごとに系統別の予定工数と供給能力を表示(§5) |
| #4 | **依存と遅延** | タスクは**前提成果物**を持つ。未納品ならブロック中で着手できず、遅れは後続に伝播する(§6) |
| #6 | **週末イベント** | イベントは**週末**に起き、**次週の計画を崩す**。主要イベントには受ける/交渉する/断るの選択肢がある(§7) |
| #7 | **専門スキルの取り合い** | 割り込みカードにも**必要スキル**がある。計画タスクと突発対応で同じ専門家を取り合う(§8-4) |
| #9 | **操作と情報設計** | **クリック配置**を標準化、**配置プレビュー**、固定 HUD(CS・予算・今週の目標)、既定を**等倍表示**に(§10) |

## 遊び方(ホットシートUI)

1. **設定** — プレイヤーとプロジェクトシートを選んで「ゲーム開始」。
   バランス数値とシードは「詳細設定」に入っています
2. **スコープ会議** — スコープボードで **Must / Better / 見送り** と**期限**を確認します。
   PM は「👑 交渉」から Must の Better 化・見送り・期限延長ができます(コストと回数の上限あり)。
   サプライのタスク候補をクリックして、**どの週にやるか**を決めて計画ボードに置きます
3. **朝会** — ミープルを**クリックして選択** → 光った場所をクリックで配置します
   (ドラッグ&ドロップも使えます)。配置前に**進捗・疲労・納品見込み・予算影響**が出ます。
   座れるのは**今週の予定**のタスク・割り込み・改修だけです。
   前提成果物が未納品のタスクは 🔒 ブロック中で座れません
4. **週末** — 着手したタスクの**実工数**が公開されます。人日が足りていれば「📦 納品」。
   Lv1 で納めると ⚠ 品質リスクが残ります
5. **週末のできごと** — イベントを1枚めくり、選択肢があれば選びます。結果は**来週**に効きます
6. **再計画** — 予定週の移動・見送り・新規配置を行い、「次の週へ」
7. **フェーズ終了** — 期限を迎えた要件を**1回だけ**清算します(Must 未達で CS 減、Better 達成で CS 増、
   Must 全達成で信頼ボーナス)。第4フェーズ終了で**最終検収**と勝敗判定

- 右下の `1:1` で等倍表示、`⤢` で全体表示に切り替わります
- 左下の「📜 ログ」から進行ログ・Undo・リセットが使えます

## バランスシミュレーション

エンジンをそのまま駆動するボットで、モンテカルロを回せます(シード付き乱数なので完全に再現します)。

```bash
pnpm --filter @smart-project/engine sim                          # 既定設定 × 全戦略
pnpm --filter @smart-project/engine sim -- --games 500
pnpm --filter @smart-project/engine sim -- --sweep mustMissCs=1,2,3
pnpm --filter @smart-project/engine sim -- --inflow experience,triage,pressure
pnpm --filter @smart-project/engine sim -- --demand base,high
pnpm --filter @smart-project/engine sim -- --deps serial,wide
```

結果と所見は **[RULES.md §13](docs/RULES.md)** にまとめています。要点:

- ✅ v4.1 の課題だった「成り行き戦略が最強」は解消(#8 の Better・信頼ボーナスが効いている)
- ✅ **計画ボードは機能している**(再計画 9.8回/ゲーム、過負荷を承知で選ぶ週が 37%)
- ✅ **専門家の取り合いは起きている**(系統単位の競合週 33.6%。#7 の狙いどおり)
- ❌ **チーム全体ではジレンマが起きていない**(需要/供給 0.62 = 全部できてしまう)
- ❌ **謝絶がまったく使われない**。チームに手空きがあり、割り込みを無料で吸収できるため
- ⚠ **速く Lv1 で出す戦略が依然最強**。v5.1 で §2-4-6(粗い土台は後続を重くする)を入れて
  品質投資は報われる方向になったが、依存チェーンが直列でテンポの価値が大きすぎて順位は変わらず

毎回の実行で **①計画の質 / ②実施ジレンマ** の指標が出ます(RULES.md §13-6)。
